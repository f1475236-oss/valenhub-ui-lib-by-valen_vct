# Introduction

**Valen UI** gives you a complete hub out of one file: a draggable window with a tab menu, cards you can pin or pull out, and a full set of controls (toggles, sliders, dropdowns, graphs and more). Every control saves itself to config automatically unless you tell it not to.

* **No dependencies.** One loadstring, nothing else.
* **Executor-safe.** Pure ASCII, works where file access is available and degrades gracefully where it isn't.
* **Yours to brand.** Override the font, theme colors and accent per window — see [Theming](window/theming.md).
